# H02 — 소비자 코어

## 범위
온보딩(언어→소개→MY ZONE) · 통합 홈 · Living · Habit · Salon

## 수용 기준
- [ ] 온보딩: 언어 선택은 화면 언어만 결정 (모드 개념 없음), ZONE 선택이 이후 화면 기준이 됨
- [ ] 홈: AI 카드 스택 (걸음 / 혜택 +HRP→지갑 / 명상 클래스→Habit / Salon 추천→Salon), 다크 히어로 1개 원칙
- [ ] Living: 6카테고리 (EAT/MOVE/SHOP/STAY/EXPERIENCE/BEAUTY) + Consumer First 랭킹 목록 (순위 뱃지, NEW boost는 2번째 위치)
- [ ] Habit: 걷기(검증형 +10HRP+2CP)·물 8잔·달리기·명상·마스크팩, 셀프 체크 일일 상한 문구, 주변 명상 장소 3곳 연결(습관→지역 퍼널)
- [ ] Salon: 4서비스 바로 예약, 피부 분석(뷰티 프로필 — "의료 진단 아님" 문구 필수), 프로필→케어·제품 추천 연결
- [ ] 예약 완료 시 HRP/CP 적립이 지갑 내역에 즉시 반영
