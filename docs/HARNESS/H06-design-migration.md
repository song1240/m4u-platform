# H06 — v10 기능의 마스터 UI 이식 (최우선)

## 목표
`src/App.jsx`(v10)의 기능·플로우를 마스터 UI 디자인(`src/master-ui/`)으로 이식한다.
**기준은 디자인=마스터 UI, 기능·정책=v10.** 이식하면서 모듈 구조로 작성해 H01(분리)을 흡수한다.

## 원칙
1. 스타일은 `style.css` 클래스와 마스터 컴포넌트(Card/Btn/Head/Zone/Tile)만 사용 — **신규 인라인 스타일 금지**
2. 새 패턴이 필요하면: DESIGN_SYSTEM.md에 정의 → style.css에 클래스 추가 → 사용 (이 순서)
3. v10에서 가져올 것은 기능·데이터·정책 문구뿐 — 인라인 스타일 복사 금지
4. 이식하는 모든 화면에 `L(lang, ko, vi)` 이중언어 적용 (마스터 UI 현재 한국어 → 이식 시 필수)
5. 화면 단위로 진행 — 한 화면 = 한 커밋 = verify 1회
