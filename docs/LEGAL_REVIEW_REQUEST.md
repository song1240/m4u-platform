## 1. 요청 배경 — 왜 지금인가

M4U는 아직 프로토타입이며 **서버가 없고 개인정보를 저장하지 않는다.** 지금 자문을 요청하는 이유는:

1. **스택 확정 전이다.** Supabase 리전을 어디로 두느냐에 따라 국외 이전 의무가 달라진다.
   구축한 뒤에 옮기면 비용이 크다.
2. **동의 UX는 온보딩 화면 구조를 바꾼다.** 화면을 다 만든 뒤 동의 항목이 늘면 재작업이 발생한다.
3. **건강 데이터 연동을 앞두고 있다.** 민감정보로 분류되면 설계 자체가 달라진다.

## 2. 사실관계 (자문에 필요한 정보)

### 2.1 사업·조직

| 항목 | 내용 |
|---|---|
| 서비스 | 베트남 호치민시 빈홈 그랜드 파크(Vinhomes Grand Park) 생활권 기반 로컬 생활 플랫폼 |
| 이용자 | 해당 단지 **거주자** — 베트남인 및 거주 외국인(한국인 포함) |
| 이용자 규모 | 미출시. 초기 목표는 단지 단위 |
| 개발·운영 조직 | **한국** (본사 Admin은 한국어 전용 내부 시스템) |
| 법인 형태 | **확인 필요** — 베트남 법인 설립 여부가 자문 답변에 영향을 줄 수 있음 |

### 2.2 기술 스택 (예정)

- 앱: Expo React Native
- 백엔드: **Supabase** (리전 미확정) · 자동화: n8n
- 현재: React(Vite) 프로토타입, **서버·DB 없음. 데이터는 브라우저 로컬에만 존재**

### 2.3 처리 예정 개인정보

| 구분 | 항목 | 비고 |
|---|---|---|
| 계정 | 식별자, 언어(ko/vi), 생활권(단지 내 구역 선택) | 정밀 위치(GPS)는 **수집 안 함** |
| 거래 | 예약 · 주문 · 숙박 · 결제 내역 | 리워드 적립의 근거 |
| **건강** | **걸음 수 등** — Apple 건강 / Google Fit 연동 **예정** | **민감정보 해당 여부가 핵심 쟁점** |
| 콘텐츠 | 커뮤니티 게시물, 사진, 댓글 | 이용자가 직접 작성 |
| 운영 | 신고 · 차단 기록 | 어뷰징 대응 |
| 어뷰징 신호 | 게시 시각, 게시물 유사도 해시 | **IP·기기 식별자는 현재 "수집 안 함"이 기본값** |

### 2.4 이미 정한 내부 원칙

- 최소 수집 / 목적 제한 / 보관 기간 한정 / 접근 통제(2인 승인 + 감사 로그) / 자동 조치의 설명 가능성
- 어뷰징 목적으로 수집한 값을 **마케팅·랭킹·추천에 재사용하지 않는다**
- **IP·기기 식별자는 필요성이 입증되고 법률 검토를 통과하기 전까지 수집하지 않는다**

## 3. 질의 사항

### Q1. 적용 법령과 역외 적용

- 한국에 있는 조직이 베트남 거주자에게 서비스를 제공할 때 **베트남 개인정보 보호법
  (Law No. 91/2025/QH15, 2026-01-01 시행) 및 시행령(Decree 356/2025/ND-CP)**이 적용되는가?
- **한국 개인정보 보호법**이 동시에 적용되는가? 두 법이 충돌하는 지점이 있는가?
- 베트남 **법인 설립 여부**가 위 결론을 바꾸는가?

### Q2. 국외 이전 — **가장 시급**

- Supabase를 **베트남 외 리전**에 두면 국외 이전에 해당하는가?
- 해당한다면 **국외 이전 영향평가(CTIA) 제출 의무**의 요건·시점·양식은?
  (최초 이전일로부터 60일 내 제출이라는 자료가 있으나 확인 필요)
- **베트남 내 저장(로컬라이제이션)이 요구되는 데이터**가 있는가?
- 위반 시 제재 수준은? (직전 연도 매출의 일정 비율이 거론되나 확인 필요)
- **실무 질문**: 리전을 어디로 두는 것을 권고하는가?

### Q3. 건강 데이터

- HealthKit / Google Fit에서 받는 **걸음 수**가 민감 개인정보에 해당하는가?
- 해당한다면 별도 동의·안전조치·보관 요건은?
- **걸음 수를 서버에 저장하지 않고 "목표 달성 여부(true/false)"만 저장**하면 부담이 줄어드는가?
  (설계로 회피 가능한지가 실무상 중요하다)

### Q4. 동의 획득

- 온보딩에서 **분리해서 받아야 하는 동의 항목**은 무엇인가? (필수/선택 구분 포함)
- 동의 문안의 언어 요건은? (한국어·베트남어 **양쪽 제공** 예정)
- 이용자가 **동의를 철회**했을 때 이미 지급된 리워드(HRP/CP) 기록은 어떻게 처리해야 하는가?

### Q5. 어뷰징 신호 (IP · 기기 식별자)

- 어뷰징·부정 이용 방지 목적의 **IP 주소, 기기 식별자 수집**이 허용되는가?
  허용된다면 근거(동의 / 정당한 이익 등)와 **보관 기간 상한**은?
- 게시물 **유사도 해시**만 보관하고 본문 원문은 보관하지 않는 방식은 문제가 없는가?

### Q6. 미성년자

- 미성년자 보호 기준 연령과 **보호자 동의 획득 방법**은?
- 단지 거주 가족 단위 서비스라 실제로 발생한다. **연령 확인을 어느 수준까지** 해야 하는가?

### Q7. 정보주체 권리

- 열람 · 삭제 · 정정 요구의 **처리 기한**과 절차상 요건은?
- **삭제 요구와 보존 의무가 충돌**할 때(예: 신고 기록, 결제·세무 기록) 우선순위는?

### Q8. 신고 · 모더레이션

- 커뮤니티 신고 기록의 **보관 근거와 기간**은?
- 신고자 **익명성** 보장 요건이 있는가?
- 자동/수동 조치(게시물 비공개, 계정 제한)에 대해 **이의 제기 절차**가 법정 의무인가?

### Q9. 조직 의무

- **현지 대리인 지정 / DPO(개인정보 보호책임자) 지정** 의무가 있는가?
- 등록·신고 절차와 **소요 기간**은? (조직 구성은 리드타임이 길어 미리 알아야 한다)

### Q10. 우선순위

- 위 사항 중 **출시 전 반드시** 갖춰야 하는 것과, **출시 후 정비 가능한** 것을 구분해 달라.
