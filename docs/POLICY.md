# M4U 제품 정책 (확정본)

> 이 문서의 정책은 코드보다 우선한다. 개정은 대표 승인 후에만 가능하며, 개정 시 CR_LOG에 기록한다.
> 모든 수치는 데모 자리표시자이며, 단위 경제 검증 후 확정한다. (수치 ≠ 정책. 원칙이 정책이다.)

## 1. Consumer First Ranking

- 순위 요소: 별점(Verified) · 재이용률 · 예약 이행률 · 취소율(감점) · 응답 속도 · 소비자 Reward 환원
- **광고비·플랫폼 납부액은 어떤 경우에도 순위에 반영하지 않는다.**
- 신규 파트너는 discovery boost로 최소 노출 보장(목록 2번째 위치), 실이용 리뷰 확보 시까지.
- 파트너에게는 순위 개선을 "광고 구매"가 아니라 "서비스 개선"으로 안내한다.

## 2. Verified Review

- 실제 M4U 예약·결제 이용자만 작성 가능.
- 보상은 **좋은 별점이 아니라 성실한 작성**에 지급 (+5CP).
- 이상 탐지: 동일 기기/IP 반복, 미이용 계정 작성 시도, 단시간 대량 작성 → Admin 플래그.

## 3. HRP — HARU REWARD POINT

- 결제·적립용 리워드 포인트. Living·Habit·Salon 전 영역의 보상이 하나의 지갑으로 모인다.
- 발행·소각은 Admin SUPER 권한 + 2인 승인(4-eyes) + 감사 로그.
- 추후 유틸리티 토큰 전환 대상이나, **현 단계 사용자 노출 문구에 코인/토큰 표현 금지** (베트남·한국 규제 대응). Web2 구조로 운영 후 온체인 1:1 이관 전제.

## 4. CP — 기여 포인트

- 양도·구매·수동 발행 **불가**. 검증 가능한 활동에만 규칙 기반 자동 적립.
- 적립 예: Verified 리뷰 +5, FIVE 참여 +10, 예약 이행 +3, 스테이 완료 +5, 파트너 승인 +50, 걷기 목표(헬스 데이터 검증) +2.
- 용도: 커뮤니티 투표 가중치. 추후 SBT/온체인 거버넌스로 동일 구조 이관.

## 5. Habit 보상

- 검증형(헬스 데이터 연동: 걷기 등)만 CP 지급. 셀프 체크는 소액 HRP + 일일 상한(15 HRP), 하루 1회·해제 불가.
- 습관은 지역 시설과 연결한다 (명상 → 주변 명상 장소 예약 → 지역 소비 → Verified Review).
- 의료성 표현 금지: "피부 진단" → "피부 분석 / 뷰티 프로필". 뷰티 프로필 화면에 "의료 진단이 아님"을 명시.

## 6. M4U FIVE 공동구매

- 5/10/15인 방, 할인 40/45/50%, 보상 HRP 20/40/60, 모집 72/96/120시간.
- 보상은 **구매 건수 비례** (인원 모집 비례 금지 — 방문판매법 리스크 회피).
- 미달 시 자동 취소 + 전액 환불. 이 문구를 참여 화면에 항상 노출.

## 7. Host 보상 (숙소 제공자)

- Host = M4U 생활권 유입 파트너. 객실별 Guest QR로 귀속 (ROOM → HOST).
- **3원칙 (절대 규칙)**
  1. **1단계 추천 보상만** — Host가 다른 Host를 모집해 수익을 얻는 구조 금지 (다단계 방지).
  2. **귀속 한정** — 체크인~체크아웃 기간만 귀속, Host 본인 계정 결제는 보상 제외.
  3. **프라이버시** — Host에게 투숙객 개별 결제 내역 비노출. 집계 수치·카테고리만 제공.
- 보상률(예시 2%)·수수료 배분은 업종별 마진과 베트남 현지 규정 검증 후 확정.
- 개인 Host 지급 시 베트남 원천징수 처리.
- M4U Recommended Stay 등급은 이용률·만족도 기반 — 돈으로 살 수 없다.

## 8. 파트너 모드

- 앱 분리 없음: M4U 하나 + 파트너 모드. 하나의 계정 · 하나의 지갑.
- 역할: 로컬 비즈니스 / SALON / MOBILITY / HOST — MY BUSINESS 화면은 역할별로 자동 구성.
- 등록: AI 대화 → 구조화 초안 → 필수 확인 3종(사업자·위치·업종 서류) → Admin 승인 → MY BUSINESS 생성 +50CP.
- 본사 운영은 별도 Admin Web (소비자 앱에 관리 기능 미노출).

## 9. 표기 규칙

- HRP 정식 명칭: **HARU REWARD POINT**.
- 단지명: **빈홈 그랜드 파크 / Vinhomes Grand Park** ("비노" 금지).
- 이중언어: 사용자 노출 문자열은 한국어/베트남어 모두 제공 (`L(lang, ko, vi)`).

## 10. M4U Contributor (기여자 네트워크)

- 모든 파트너는 Contributor — 고유 QR(Room/Table/Counter/Mirror/Vehicle/Class QR 등)이 M4U의 오프라인 유입 채널이 된다.
- **보상 2분리 (절대 규칙)**
  - ① Transaction Reward: 직접 거래를 만든 것에 대한 제휴 보상 (예: Host 객실 QR → Spa 예약).
  - ② Ecosystem Contribution Reward: M4U 성장 기여 보상 — **검증된 행동**(신규 가입 → 첫 실제 이용 → Verified Review)에만 적립.
- **랭킹 방화벽**: 기여점수(Contribution Score)는 Consumer First Ranking과 검색 품질에 **절대 반영하지 않는다**. 노출 혜택은 Contributor 배지와 별도 Contributor 섹션 노출로 한정한다.
- **시효**: 유입 기여 기록은 영구 보존하되, 보상은 가입 후 90일 내 검증 활동까지만 적용한다(수치는 데모 — 재무 검증 후 확정).
- **1단계 한정**: 유입 보상도 다단계 구조 금지. 자기 유입(본인·직원 계정)은 자동 제외.
- **재원**: Ecosystem 보상의 재원은 거래 수수료가 아니라 마케팅 예산(광고비 대체)이며, 1인당 보상 상한은 예상 LTV 기준으로 설정한다. 현금성 지급 시 원천징수 처리.
- **장부 분리**: 소비자 CP와 파트너 Contribution Score는 철학(검증된 기여만·구매 불가)을 공유하되 장부를 분리한다 — 커뮤니티 투표 가중치에 사업자 기여 혼입 금지.
- 혜택 4종: 기여 보상 · 배지/별도 노출 · 사업 도구(프로모션·AI Manager·고객 분석 등급제) · 거버넌스 기여는 Web3 단계에서 검토.
